# USB Camera と映像品質の調査（2026-10-28）

## 既存アプリの試験

インストール済み USB Camera 12.3.0 で、XREAL 1S の USB 2.0 接続と HEVC 2048×1512 のプレビューを確認した。表示フレームレートは約59.4 fps。HEVC Bypass のアプリ内説明は、UVC の HEVC を IP Camera Server に再エンコードせず出力するとしており、ローカル録画のバイパスを保証していない。

約21秒のローカル録画試験では、出力 MP4 は約4 KB で映像フレームを認識できず、ログには 2048×1512・30 fps の AVC エンコーダ起動が記録された。この試行は使える録画にならなかったが、すべての設定でローカルの無変換録画が不可能と証明したものではない。音声の入力元も未確認。アプリには USB 音声が利用できない場合に端末マイクへ切り替える旨の警告があり、独立ステレオの実現は確認できていない。

ユーザーの許可で IP サーバーを一時起動した。HTTP 8081 と RTSP 8554 が全インターフェースで待ち受け、認証なしでは RTSP は 401 を返した。設定済み認証情報での接続は TCP 接続まで確認できたが、試した `/live` では制限時間内に映像情報を取得できず、HEVC の無変換保存は未検証。終了時点では両ポートの待受がないことを確認した。URL や認証、サーバー側状態を含め原因は未確定。

## 本体録画との画質比較

ユーザーは自作アプリの映像が本体直接録画より非常にノイジーと報告した。23:36 の自作アプリ録画は HEVC 2048×1512、映像平均約 2.05 Mbps。raw HEVC と MP4 の映像 VCL NAL は既存調査で全4,289個が一致し、この録画の全デコードで FFmpeg エラーはなかった。これは保存・コンテナ格納による再エンコードを支持しないが、カメラ側の圧縮、露出やノイズ処理、UVC 受信以前の品質、または他の受信上の問題を除外しない。ビットレートだけで画質劣化の原因は断定できない。

本体の直接録画と自作アプリ録画を同じ場面・照明で比較し、解像度、フレームレート、ビットレート、静止画のノイズと細部、および各経路の設定を調べる。本体の比較動画の場所はユーザーに確認中。USB Camera のプレビューを同条件で比較する際は、前回試験中にカメラ調整画面で意図せず設定値に触れた可能性があり、元の値も不明な点に注意する。RAW 独立ステレオ以上の音声調査は引き続き別キューに残る。
