- スマートフォン上の XREAL 1S の sysfs speed は 480 Mbps。これは調査時の値であり、撮影時のログではない。
- 19:36:48 の MP4 は HEVC 2048×1512 と AAC 48 kHz モノラルを含む。AAC は無音。
- 同じ録画の WAV は 48 kHz、32-bit、ステレオ、8,496,000 フレーム。全 16,992,000 サンプルがゼロ。従って AAC 変換以前の PCM が無音。
